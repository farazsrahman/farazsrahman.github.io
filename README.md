# Standalone Site

This is a standalone HTML + CSS version of the website, extracted from the Jekyll site. All paths have been converted to relative paths, so you can open `index.html` directly in a browser or serve it from any web server.

## Structure

- `index.html` - Home page
- `projects.html` - Projects page
- `about/index.html` - About page
- `contact.html` - Contact page
- `quote-wall.html` - Blog post page
- `404.html` - 404 error page
- `assets/` - CSS, JavaScript, and icons
- `images/` - Image files
- `pdfs/` - PDF documents

## Usage

Simply open `index.html` in your web browser, or serve the entire folder using any web server.

## Notes

- All paths are relative, so the site will work regardless of where it's hosted
- External links (to GitHub, arXiv, etc.) remain unchanged
- The site uses Bootstrap CSS and FontAwesome icons (loaded from local files)
- Google Fonts are still loaded from Google's CDN
